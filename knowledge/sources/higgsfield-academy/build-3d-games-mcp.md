Build and publish three no-code 3D game prototypes with an MCP-connected workflow, then compare output, cost, and early marketplace results.

## What you'll learn

- Connect the MCP workflow and build three distinct game prototypes
- Publish a prototype to the marketplace with the required presentation assets
- Compare MCP-assisted work with Claude alone, then evaluate cost, early results, and studio feedback
